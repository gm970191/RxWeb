# 高效沟通与协作经验总结

## 1. 明确需求与目标
- 在每个阶段开始前，项目经理应明确提出需求、目标和验收标准。
- 需求变更要及时同步，避免信息滞后。

## 2. 结构化表达与反馈
- 采用结构化的设计文档、问题清单、阶段总结，便于双方快速定位问题。
- 每次关键操作后及时总结、确认。

## 3. 问题定位与复盘
- 出现问题时，先收集详细日志和环境信息，逐步排查。
- 复盘每个失败点，记录原因和解决办法，形成知识库。

## 4. 工具与流程标准化
- 推荐使用自动化工具（如 `start-server-and-test`）减少人为操作。
- 统一端口、依赖、脚本命名等规范，减少沟通成本。

## 5. 语言与表达
- 明确指定沟通语言（如本项目全程中文），避免歧义。
- 复杂问题建议分步描述，逐条确认。

## 6. 经验教训
- 充分利用自动化和标准化工具，提升协作效率。
- 及时总结和同步问题，持续优化沟通方式。
- 形成文档化沉淀，便于团队成员快速上手和复用。
