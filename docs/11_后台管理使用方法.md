# 后台管理使用方法

本文给负责改网站内容的人。说明怎么登录、四个菜单分别做什么、改完后前台哪里能看到。接口和表结构见 [03_API_Endpoints.md](./03_API_Endpoints.md)、[02_Database_Design.md](./02_Database_Design.md)。

后台只管这一家网站数据库里的新闻、产品和留言。公司名称、页头页脚、联系方式和下载页条目写在 `deploy/sites/<站点>/profile.js` 里，后台改不了。

## 1. 怎么进入

1. 浏览器打开该站首页。本机一般是 `http://127.0.0.1:8001`。调试机按站点分端口：

   | 站点 | 调试机地址 | 管理员邮箱 |
   |------|------------|------------|
   | 瑞学 | `http://47.97.245.103:8001` | `admin@rxweb.com` |
   | 艾尔德 | `http://47.97.245.103:8009` | `admin@aierde.example` |
   | 益如驰 | `http://47.97.245.103:8010` | `admin@yiruchi.example` |

2. 点页头「登录」，进入 `/login`。用管理员邮箱和密码登录。种子数据写入后的默认密码是 `rxweb123`。环境变量 `RXWEB_ADMIN_PASS` 只影响之后新建的管理员，不会改已经存在的密码。
3. 登录成功后，页头会出现「后台」。也可以直接打开 `/admin`，会进入新闻管理。
4. 右上角显示当前管理员姓名，点「退出登录」回到登录页。

未登录访问 `/admin` 会先跳到登录页。普通用户（包括登录页自己注册的账号）没有「后台」入口；若直接打开 `/admin`，会进「我的留言」（`/account`）。登录页注册出来的账号角色都是普通用户，不能靠注册变成管理员。

右上角「修改密码」可改当前账号的密码。需要填写当前密码，新密码至少 6 位。忘记当前密码时，在登录页点「忘记密码」，填写管理员邮箱。服务器配了发信才会把重置链接发到邮箱；没配发信时，页面上会直接给出重置链接。

## 2. 页面长什么样

进入后左侧四个菜单，右侧是当前功能：

| 菜单 | 地址 | 作用 |
|------|------|------|
| 新闻管理 | `/admin/news` | 新增、编辑、预览、删除新闻 |
| 产品管理 | `/admin/products` | 新增、编辑、删除产品 |
| 留言管理 | `/admin/messages` | 查看访客留言并写下回复 |
| 操作日志 | `/admin/logs` | 查看谁在什么时候做了什么，只读 |

手机上左侧菜单会折成一排按钮，表格可以左右滑动。

保存成功或失败时，页面顶部会弹出提示。删除前会再问一次「确定要删除吗」，点取消则不删。删除后不能在后台恢复。

## 3. 新闻管理

列表按日期从新到旧排列，每页 10 条。底部可翻页。

顶部可按「全部 / 已发布 / 草稿」筛选。搜索框匹配标题、摘要、来源。输入后按回车，或点「搜索」。搜索和切换筛选都会回到第 1 页。

**新增：** 点「新增新闻」，填完点「保存」。标题、日期、来源、摘要、正文都必填。新新闻默认是「草稿」。

**编辑：** 点该行「编辑」。对话框会带出已保存的正文和状态，改完点「保存」。

**预览：** 点「预览」，在弹窗里看标题、日期、来源、摘要和正文。草稿也能预览。这是后台预览，不是前台页面。

**删除：** 点「删除」，确认后这条新闻消失。

状态：

- **草稿**：只在后台看得到。前台新闻列表和详情都不会出现。
- **发布**：保存后立刻出现在「新闻动态」。

填写时注意：

- 日期用日期选择器，格式是 `YYYY-MM-DD`。前台新闻列表按这个日期排序，日期越新越靠前。
- 正文是纯文本。换行会保留，空一行就是分段。不要贴 HTML，标签会原样显示出来。
- 来源会显示在新闻详情的「来源」一栏，例如「官方新闻」「公司动态」。

发布后，打开网站「新闻动态」（`/news`）可看到标题、日期、来源和摘要；点进去是详情（`/news/编号`），正文在详情页。

## 4. 产品管理

列表按「排序」从小到大排列，每页 10 条。搜索匹配名称、分类和描述。输入后按回车或点「搜索」。

图片加载失败时，该行显示「图片失效」。没有填图片时显示「未配图」。

**新增：** 点「新增产品」。名称、价格、分类、描述必填。图片可以空着。排序默认排到现有产品后面。

**编辑：** 点该行「编辑」，改完点「保存」。

**删除：** 点「删除」并确认。前台产品列表和详情都会去掉这一条。产品图文件会留下，可在选图窗口里删除没有产品使用的上传图片。

各栏怎么填：

| 栏 | 说明 |
|----|------|
| 名称 | 产品列表和详情的标题 |
| 价格 | 只填数字（如 `399` 或 `399.00`）时，前台显示为 `￥399`。填「面议」或其他文字时，前台原样显示 |
| 分类 | 下拉列出已有分类，也可以输入一个新分类。保存时会去掉首尾空格。同一类产品请用完全相同的文字 |
| 排序 | 数字越小越靠前，范围 0 到 999999。首页没有单独指定推荐产品时，取最靠前的几条 |
| 图片 | 可手填地址，也可「选择已有图片」或「上传图片」。上传只接受 jpg、png、webp，单张不超过 2MB。上传后地址形如 `/media/products/一串编号.jpg` |
| 描述 | 产品详情里的介绍，纯文本 |

手填地址可以是完整网址（以 `http://` 或 `https://` 开头），也可以是站内路径（如 `/media/products/mask-care.png`）。填了之后对话框里会显示预览。

选图窗口里每张图有标记：

- **使用中**：至少有一条产品指向它，不能删。
- **未使用**：后台上传的、当前没有产品使用，可以在这里删除。
- **随站点发布**：构建网站时带上的图。这里不能删，要改的话去该站 `deploy/sites/<站点>/media/products/`。

上传的文件放在网站目录的 `media/products/`，不放进 `frontend/dist`。下次发布会覆盖 `frontend/dist`，但不会清掉这个 `media` 目录，已经上传的图还在。

保存后到「产品中心」（`/products`）查看。分类筛选来自已有产品的「分类」字段。

## 5. 留言管理

访客在「联系我们」提交的留言出现在这里，按时间从新到旧，每页 10 条。

顶部三个筛选：

- **全部**：所有留言
- **待回复**：还没有保存过回复的，按钮上的数字是待回复总数
- **已回复**：已经保存过回复的

点某一行的「查看/回复」，可看到姓名、邮箱、时间、主题和正文。在下方文本框写下回复，点「保存回复」。回复不能为空。

回复会保存在网站里。若该站配置了发信（`SMTP_HOST`），保存时还会把回复寄到留言邮箱，并提示「已发到对方邮箱」。没配发信时，页面会说明邮件未发送。无论是否发信，访客都要用留言时填写的同一个邮箱登录，到页头「我的留言」（`/account`）查看。邮箱对不上的登录用户看不到这条回复。邮件发送失败时，回复仍然保存成功。

再次打开已回复的留言，文本框里是上次的回复。再点「保存回复」会覆盖旧内容，状态仍是「已回复」。

## 6. 操作日志

这里只查看，不能改、不能删。每页 20 条，最新的在最上面。

搜索匹配操作人、动作、详情、IP。页面上的动作名称对应这些记录：

| 页面上的名称 | 什么时候写下 |
|--------------|----------------|
| 登录成功 / 登录失败 | 有人登录 |
| 退出登录 | 点了退出 |
| 用户注册 | 有人在登录页注册 |
| 申请重置密码 / 密码已重置 | 走了忘记密码流程 |
| 修改密码 | 在后台改了自己的密码 |
| 新增新闻 / 编辑新闻 / 删除新闻 | 新闻管理里的保存或删除 |
| 新增产品 / 编辑产品 / 删除产品 | 产品管理里的保存或删除 |
| 上传产品图 / 删除产品图 | 产品图窗口里上传或删除图片 |
| 访客留言 | 有人在联系我们提交留言 |
| 回复留言 | 留言管理里保存了回复。配了发信时，详情里会写是否发出 |

「结果」为成功或失败。失败时「详情」里会带原因。

同一份记录还会追加到网站目录下的 `logs/rxweb-ops.log`。后台打不开时，可以直接看这个文件。它和 `logs/rxweb.log` 不是同一个：后者是程序启动日志。

## 7. 后台做不到的事

- 不能上传 Logo、首页轮播和关于我们配图。这些仍放在该站 `media/brand/`，并写在 `profile.js`。
- 不能改公司名称、电话、地址、首页文案和下载列表。这些在对应站点的 `profile.js`，改完需要重新构建发布。
- 不能新建或停用管理员，也不能把普通用户提成管理员。
- 删除的新闻和产品没有回收站。删除产品不会连带删除图片文件。
