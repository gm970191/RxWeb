# 从零开始：RxWeb 是什么、怎么学

本文给完全没有部署经验的同学。读完你应能回答：网站是怎么跑起来的、该先装什么软件、该看哪份文档。

## 1. 这个项目是什么

RxWeb 是「瑞学软件」公司官网：首页、产品、新闻、下载、联系我们，以及简单的新闻后台。

它分成两块，最后用 **同一个端口 8001** 对外提供服务：

| 名称 | 技术 | 通俗理解 |
|------|------|----------|
| 前端 | Vue 3 + Vite | 你在浏览器里看到的页面、按钮、布局 |
| 后端 | Python FastAPI | 提供数据的接口，例如 `/api/news`、`/api/products` |
| 数据库 | SQLite 文件 `company.db` | 新闻、产品等数据存在一个文件里，不是单独安装的 MySQL |

开发时可以前后端分开跑；**部署到服务器时**，先把前端编译成 `frontend/dist`，再由 FastAPI 把页面和接口一起挂出去。所以生产环境只需要启动 **一个** Python 进程。

## 2. 一次访问是怎么走的

1. 浏览器打开 `http://服务器IP:8001/`
2. FastAPI 发现有 `frontend/dist/index.html`，把官网 HTML 发给你
3. 页面里的 JavaScript 再请求 `/api/products`、`/api/news`
4. FastAPI 读 `company.db`，把 JSON 数据返回给页面
5. 页面把数据渲染成列表、详情

如果没有 `frontend/dist`，打开首页只会看到一句 JSON：「欢迎访问瑞学软件后端API」。这不是坏了，是前端还没构建。

## 3. 新手必须认识的词

- **端口（port）**：同一台电脑可以跑很多服务，用数字区分。测试 / 生产默认 **8001**（页面 + `/api`）。本机热更新时后台另用 **18001**。
- **虚拟环境（venv）**：项目自己的 Python 依赖目录。Windows 的 `backend/venv` **不能**拿到 Ubuntu 上用。
- **npm / Node.js**：用来安装前端依赖、执行 `npm run build` 把 Vue 编译成静态文件。
- **uvicorn**：真正把 FastAPI 跑起来的程序，启动脚本最后调用的就是它。
- **进程（PID）**：正在运行的程序。`--daemon` / `-Daemon` 会把 PID 写进 `rxweb.pid`，方便停止。
- **Docker**：把环境和网站打成镜像，Windows / Ubuntu 用同一套命令运行。见 [09_Docker部署与运行.md](./09_Docker部署与运行.md)。

## 5. 三种运行方式对比

| 方式 | 适合谁 | 你要装的东西 |
|------|--------|----------------|
| `start.ps1` | 在自己电脑（Windows）先跑通 | Python + Node.js |
| `start.sh` | 阿里云 Ubuntu / 宝塔 | python3；若 zip 里没有 dist 还要 Node |
| Docker | 本机或服务器都想「一条命令」 | 只装 Docker |

三种方式默认都是 **8001** 端口，浏览器访问方式一样。本机改 Vue 源码要立刻刷新时，再用 `start-dev.ps1`（前台 8001 + 后台 18001）。
